# Changelog

## Theme 1.1.0 — 2026-10-04

- Reworked desktop navigation spacing, current-section states and the compact header after scrolling.
- Added nested custom menus with independent parent links and disclosure buttons. The default project submenu includes public project summaries and an archive link.
- Added optional English labels and Chinese/English submenu descriptions in Appearance → Menus, without requiring the content plugin.
- Added an independently scrolling mobile panel with language/theme controls, plus an adaptive drawer for long desktop menus.
- Added keyboard disclosure controls, focus restoration, reduced-motion support and accessible links when JavaScript is disabled.
- Made WordPress test runtime versions explicit in generated Blueprints and checked the running PHP/WordPress versions in the integration fixture.
- The FLOAT Content companion plugin remains at 1.0.0. Search is deferred to a later release.

## 1.0.0 — 2026-10-03

- First public reusable edition of the FLOAT Space classic theme and optional FLOAT Content plugin.
- Generic bilingual defaults, original SVG artwork and configurable site identity.
- Removed site-specific content, contacts, registration numbers, deployment data and third-party imagery.
- Opt-in page setup, separate project content and validated configuration collections.
- Reproducible installable packages, privacy gate and isolated WordPress checks.
