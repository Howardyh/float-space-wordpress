Optional companion for FLOAT Space: projects, bilingual post metadata, homepage copy,
optional contact/registration links and validated configuration collections.

Upload and activate through Plugins > Add New. Activation does not create users,
import projects or change reading settings. Use Settings > FLOAT website copy to
explicitly create missing pages. Example projects are optional drafts only.

Draft imports do not publish records. Only valid, published, unprotected collection
records enter the read-only public API. Preferences and frontend drafts remain local.

Deactivation does not delete content. Uninstallation has no automatic database cleanup;
remove saved content through WordPress before uninstalling if that is desired.
