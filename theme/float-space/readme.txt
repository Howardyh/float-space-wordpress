A classic portfolio and blog theme with bilingual content, dark/light preferences,
pointer motion, custom logo/navigation and optional configuration collections.
Navigation supports nested menus, separate parent links and disclosure buttons,
optional English labels and bilingual submenu descriptions in Appearance > Menus.
Mobile and overflow drawers include preferences and scroll independently.
Keyboard controls, reduced motion and accessible links without JavaScript are supported.

Install and activate this theme through Appearance > Themes.
Native posts work without an additional plugin. For projects and editable bilingual
homepage content, install the optional FLOAT Content companion plugin separately.
Configure a static homepage in Settings > Reading when you want the portfolio layout.
Contact and registration information are optional and blank by default.

Original SVG artwork and fictional examples only. No third-party game imagery or
hardware photographs are included. No analytics or automatic draft upload is included.
