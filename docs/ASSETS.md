# Asset provenance

All graphics distributed in the theme are original SVGs created for this public edition. They use simple paths, shapes and text, contain no embedded photographs or remote images, and are licensed under GPL-2.0-or-later with the theme.

The theme screenshot is rendered from the public theme with fictional demo content. It contains no production-site data or administrator interface. System fonts are used; no fonts are bundled.

No third-party game artwork, game asset index, hardware photograph or original site brand mark is redistributed. Fictional catalog entries are examples only and carry no relationship to a real game or vendor. New catalog data or images supplied by site owners require their own permission and provenance review.

WordPress, PHP and WordPress Playground are external development/runtime tools and are not included in release packages.
