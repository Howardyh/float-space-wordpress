# Contributing

Keep the theme framework-free, accessible and usable with keyboard navigation and reduced motion. Keep content management in the companion plugin. Preserve nonce checks, capabilities, output escaping and publication validation.

Use fictional examples and assets with clear provenance. Do not add real contact details, site registrations, deployment paths, credentials, databases or production screenshots. Keep temporary test output outside the repository. Run the privacy gate and build the installable packages before proposing a release.

When reporting a bug, include WordPress/PHP versions, steps, expected behavior and a sanitized screenshot or console excerpt. Never paste credentials or unredacted configuration into an issue.
